\section{System Context}\label{sec:context}

The batch analyses sit inside a small system (Fig.~\ref{fig:arch}): a streaming job that scores each new leg from event-time state and reproduces the batch predictions of the \emph{served} model on all \fzStreamAllLegsIdentical{} legs, a public interface for it, and five language-model agents built on one rule, that code computes every verdict and a model only words it. We describe them in the journal version; they matter here because both evaluation pitfalls (Section~\ref{sec:pitfalls}) arose in them. The agents' evaluation sets are synthetic, and a pilot ablation of letting a model decide in place of the rules was too small to settle anything beyond the order task.
