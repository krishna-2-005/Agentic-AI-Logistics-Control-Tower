# ── Python version ───────────────────────────────────────────────────────────
# Requires Python 3.11-3.13. The constraints below are the *floors that have
# cp313 wheels*, because that is the interpreter the team is on.
#
# This bit us once, so it is written down: the obvious "stable" pins
# (numpy==1.26.4, pandas==2.2.2, pyarrow==15, scipy==1.13.1, pyspark==3.5.1)
# all predate Python 3.13 and have **no cp313 wheel**. pip silently falls back to
# building them from source, which either takes forever or fails on a machine
# without a C toolchain. If you downgrade anything here, check the wheel exists
# first:
#
#   pip download <pkg>==<ver> --no-deps --only-binary=:all: -d /tmp/x
#
# PySpark 4.0 is the first release supporting Python 3.13 (and it requires
# Java 17+, which we need anyway).
