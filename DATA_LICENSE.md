# Data licence and provenance

The MIT licence in `LICENSE` covers **this repository's source code**. It does not
cover the data the project analyses, none of which is redistributed here.

## The Delhivery trip dataset — the real data

Every number this project reports about the network comes from Delhivery's public
trip records, published on Kaggle.

| | |
|---|---|
| **Source** | *Delhivery Logistics Dataset*, Kaggle |
| **Link** | <https://www.kaggle.com/datasets/devarajv88/delhivery-logistics-dataset> |
| **Terms** | The dataset's own Kaggle licence. Read it on the dataset page before use — it governs what you may do with the data, independently of this repository's code licence. |
| **Redistributed here?** | **No.** `data/` is gitignored. `data/README.md` has download instructions and the expected file size, and `src.common.check_env` verifies it. |
| **What we use** | 144,867 scan-level segment rows across 14,817 trips, reconstructed into 26,369 origin-destination legs on 2,783 corridors. |
| **Window** | 11 September – 3 October 2018 (21 days). |

**Attribution.** If you publish work derived from this repository, cite the dataset
from its Kaggle page as well as this repository (`CITATION.cff`).

## The NYC TLC trip records — the scale appendix

The 56.4-million-row scale benchmark runs the project's own corridor-aggregation code
unchanged on public New York City taxi data.

| | |
|---|---|
| **Source** | NYC Taxi & Limousine Commission trip record data (yellow taxi, Parquet) |
| **Link** | <https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page> |
| **Terms** | Published by the TLC for public use under the terms on that page. |

## Synthetic data generated by this project

The documents the agents read and the orders they file are **generated by this
repository**, not collected. They are declared as scaffolding wherever they appear,
because an agent scored on documents produced by its own team's generator is partly
measuring the generator.

| What | Generated by | Licence |
|---|---|---|
| Bills of lading and invoices (~300–500, with seeded errors) | `src/agents/doc_corpus/` | MIT, same as the code |
| Order emails for the Order Entry evaluation | `src/agents/order_corpus.py` | MIT |
| The mock TMS database | `src/tms/seed.py` | MIT — though its 1,657 facility codes are the real ones from the Delhivery data |

GSTINs in the synthetic documents are **shape-valid but not checksum-valid** by
deliberate choice (D-021): right length, right character classes, a real state-code
prefix, and a random final character, so nothing generated here could be mistaken for
a real, checkable GSTIN.
