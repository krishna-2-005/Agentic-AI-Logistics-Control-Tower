# The paper

The manuscript is LaTeX, not Markdown, and every number in it is a macro generated from the newest results freeze.

| | |
|---|---|
| **Conference version** (Springer LNCS, about 15 pages) | [`paper/conference/main.tex`](../paper/conference/main.tex) |
| **Journal version** (about 30 pages; adds the streaming, scale and agent-study sections, an extended related-work section, a reproducibility statement and an appendix) | [`paper/journal/main.tex`](../paper/journal/main.tex) |
| **Shared sections** | [`paper/sections/`](../paper/sections/) (one file per section; the journal version includes the conference sections and adds its own) |
| **Numbers** | [`paper/numbers.tex`](../paper/numbers.tex), generated by `python -m src.report.paper_numbers` from [`benchmarks/results_freeze_v6.json`](../benchmarks/results_freeze_v6.json); a test fails if a manuscript uses a macro the freeze does not define |
| **Bibliography** | [`paper/refs.bib`](../paper/refs.bib) (each entry carries its verification note; `paper/refs_print.bib` is the same file without them, for printing) and [`references.md`](references.md) |
| **Build** | `make paper` or `scripts/build_paper.sh` (needs `latexmk` or `tectonic`) |
| **Venue shortlist** | [`venues.md`](venues.md); the choice is the authors' (HUMAN_ACTIONS 6.1) |
| **Self-review** | [`reviewer_simulation.md`](reviewer_simulation.md) |

The earlier Markdown draft (v0.2, written for a conference that turned out to be the wrong one, D-097) described the
corridor audit as finding 273 confirmed bottlenecks and the model as winning by 6.5% over a baseline with an unfair cold-start
fallback. Both claims were revised in the upgrade pass (D-075 to D-089); the draft is in the git history and is not maintained.
